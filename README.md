## Features

- ⚡ **Quick paste** — paste any format, get structured leads instantly
- 🤖 **Agent mode** — upload large files (1000+ rows), processed in batches
- 📧 **Email verification** — DNS / MX / SMTP checks
- 📥 **CSV export** — CRM-ready output, split into Good / Bad lists
- 🔑 **Bulk API keys** — auto-rotate Groq keys to avoid rate limits

---

## Tech Stack

- Vanilla HTML / CSS / JS (no framework)
- [Groq API](https://console.groq.com) for AI extraction
- Node.js backend for email SMTP verification
